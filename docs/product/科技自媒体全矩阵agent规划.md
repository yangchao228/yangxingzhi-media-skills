# AI Agent 自我改进系列：视频 + 图文 + 长文矩阵规划

## Summary
- 主线不变：做《Agent 进化论：自我改进 Agent》专题。
- 渠道升级：每个选题同时产出公众号长文、小红书图文、小红书短视频、抖音短视频。
- 默认策略：公众号负责深度和资产沉淀，小红书图文负责收藏，小红书视频负责信任感，抖音视频负责破圈。
- 生产原则：一篇长文不直接搬运到各平台，而是拆成不同入口、不同节奏、不同钩子。

## Production Workflow
- 每个主题先产出一份 `source-pack`：事实、案例、反方、可引用数据、不能写死的存疑点。
- 再写公众号长文：形成完整论证和可沉淀模板。
- 从长文拆小红书图文：默认 8 页，结构为封面、问题、判断、机制、案例、方法、边界、CTA。
- 从长文拆两条短视频脚本：
  - 小红书视频：偏“我为什么这么判断 + 你可以怎么做”。
  - 抖音视频：偏“一个反常识判断 + 一个例子 + 一个行动建议”。
- 每篇最终沉淀 4 类资产：长文、图文卡片、视频脚本、模板/清单。

## Publishing Rhythm
- 建议 5 周跑完第一季，每周一个主题。
- 每周节奏：
  - 周一：采证和长文定稿。
  - 周二：公众号发布。
  - 周三：小红书图文发布。
  - 周四：抖音短视频发布。
  - 周五：小红书视频发布。
  - 周末：看评论、收藏、转发、私信问题，更新下一篇角度。
- 不建议日更硬冲。这个题材需要建立专业信任，稳定比密集更重要。

## Content Templates
- 公众号标题：偏判断和框架，例如《从 Loop 到进化：自改进智能体到底多了一层什么》。
- 小红书封面：偏问题和收藏，例如《Agent 会自己变强吗？先看这 5 个条件》。
- 抖音开头：前 3 秒直接给冲突，例如“很多人说 Agent 会自我进化，我觉得先别急着兴奋。”
- 视频固定结构：钩子 3 秒、判断 10 秒、案例 25 秒、方法 20 秒、收束 5 秒。
- 统一 CTA：评论区领取“Agent 错题本 / Skill 审核表 / 自改进 Loop 模板”。

## Validation
- 起稿前核验所有高波动来源，尤其是 2026 年模型、平台、公司计划、工具数据。
- 小红书和抖音发布规格以当日创作后台为准：[小红书创作服务平台](https://creator.xiaohongshu.com/) / [抖音创作者中心](https://creator.douyin.com/)。
- 每条视频只讲一个点，不把公众号大纲压缩成口播。
- 每篇至少交付一个可复用资产，避免只做热点内容。

## Assumptions
- 默认先做低成本视频：屏录 + 字幕 + 旁白/轻口播，不强依赖真人出镜。
- 默认账号定位继续使用 AI生命克劳德 / Human3.0。
- 默认先跑 5 周验证，再决定是否加码真人出镜、系列课、资料包或私域承接。
