# 文昌最小使用指南

这份指南只保留买家第一周最常用的 3 个场景。完整流程可以继续阅读 `docs/wenchang-user-guide.md`。

## 场景 1：从一个主题开始

适合你已经知道大概想写什么，但还没有结构和素材。

复制下面模板：

```text
请使用文昌总控，从这个主题开始走内容流程。

主题：<你的主题>
账号定位：<你的账号定位>
长期方向：<你的长期方向>
目标平台：公众号
目标读者：<你的读者>
要求：
- 先判断这个主题是否值得写
- 给出 2-3 个可选切口
- 不要直接写完整文章
- 需要我拍板时停下来
```

你应该先看到选题判断和推荐链路。确认切口后，再让文昌继续采证和起稿。

## 场景 2：从热点链接开始

适合你看到一篇新闻、博客或行业文章，想判断能否转成自己的内容。

```text
请使用文昌总控，把下面这篇文章当成素材，判断是否适合写成我的内容。

素材链接：<URL>
账号定位：<你的账号定位>
长期方向：<你的长期方向>
目标平台：公众号 / 知乎 / 小红书
要求：
- 不复述原文
- 提炼适合我账号的切口
- 标出需要补充采证的事实
- 给出不建议写的方向
```

如果输出缺少来源、限制条件或反向证据，可以继续输入：

```text
请进入文昌·采证阶段，补充来源、关键事实、反向证据和可信度判断。
```

## 场景 3：从已有初稿开始

适合你已经写了一版，但不确定能不能发。

```text
请用文昌·诊文检查这篇初稿。

目标平台：公众号
账号定位：<你的账号定位>
长期方向：<你的长期方向>
要求：
- 先给结论，判断是否值得继续改
- 不要默认全文重写
- 给最小修改建议
- 判断是否适合拆成知乎或小红书

<粘贴初稿>
```

如果诊文结论是“可以轻改后发布”，再运行：

```text
请用文昌·出刊检查这篇文章，补齐标题、摘要、标签、封面文案、朋友圈文案和发布前阻塞项。
```

## 建议的第一周练习

第 1 次：拿一个你真正想写的主题跑选题判断。  
第 2 次：拿一篇热点链接跑“能不能写成我的内容”。  
第 3 次：拿一篇旧稿跑诊文，不急着重写。  
第 4 次：把最好的那篇跑出刊检查。  
第 5 次：用小红书或知乎 skill 拆分分发资产。

## 判断输出有没有跑偏

正常输出应该具备这些特征：

- 会先判断阶段，不急着写全文。
- 会给可选切口，并说明取舍。
- 会要求你确认关键判断。
- 会保留事实来源、反向证据和限制条件。
- 会把发布资产和正文修改分开。

跑偏信号：

- 直接生成一篇泛泛长文。
- 没有问账号定位和目标平台。
- 没有来源也给出强结论。
- 只给标题党，不说明读者获得感。
- 出刊阶段回头大改正文。

遇到跑偏时，直接要求：

```text
退回文昌总控，重新判断当前阶段和下一步，不要直接生成全文。
```
