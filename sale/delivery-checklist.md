# 交付与验收清单

这份清单用于买家付款后确认交付是否完整，也用于卖家避免口头承诺不清。

## 标准版交付

- [ ] `wenchang-skill-pack-v0.1.zip`
- [ ] `sale/README.zh-CN.md`
- [ ] `sale/INSTALL.md`
- [ ] `sale/USER_GUIDE.md`
- [ ] `sale/templates/` 模板目录
- [ ] `sale/examples/` 示例目录
- [ ] `sale/faq.md`
- [ ] `sale/after-sales-boundary.md`
- [ ] 核心文昌 skills
- [ ] 多平台辅助 skills

## 上手服务版交付

除标准版外，额外交付：

- [ ] 帮买家确认安装路径。
- [ ] 用买家的 1 个真实主题跑一次最小流程。
- [ ] 交付一份内容产物包，至少包括选题判断、文章 brief、发布检查或诊文结果。
- [ ] 指出后续买家应该自己确认的事实、标题、封面和发布节点。

## 买家验收方式

买家可以按下面 3 步验收：

1. 解压后能看到 `sale/` 和 `content/`。
2. 能把 `wenchang-orchestrator` 等目录放进本地 skill 目录。
3. 输入测试提示后，AI 能先判断文昌流程阶段，而不是直接生成一篇文章。

测试提示：

```text
请使用文昌总控，从主题“AI 时代个人内容系统怎么搭建”开始，先判断选题和流程，不要直接写全文。
```

## 不在交付范围内

- AI 模型账号、API Key、平台账号。
- 公众号、小红书、知乎自动发布。
- 平台审核通过保证。
- 图片上传、R2 对象存储、公开外链配置。
- 爆款、涨粉、成交、变现保证。
- 论文代写、洗稿搬运、侵权素材处理。
- 长期不限次数远程技术支持。
- 买家本机系统、网络、代理、模型客户端故障的深度排查。

## 售后建议

标准版建议提供：

- 购买后 7 天内，安装路径类问题答疑。
- 1 次基础使用问题答疑。
- 文档已覆盖的问题，引导买家阅读对应文件。

上手服务版建议提供：

- 1 次远程或文字指导。
- 1 个真实主题的流程演示。
- 不承诺后续每篇文章都免费陪跑。
