# 初稿诊文模板

适合已经有一篇初稿，需要判断是否值得继续改。

```text
请用文昌·诊文检查下面这篇初稿。

目标平台：
公众号

账号定位：
<粘贴账号定位>

长期方向：
<填写长期方向>

要求：
- 先给结论：值得继续写 / 轻改后可发 / 需要重构 / 暂不建议发
- 不要默认全文重写
- 找出 3 个最影响发布的问题
- 给最小修改建议
- 判断是否适合拆成知乎或小红书
- 给出长期资产判断

初稿：
<粘贴初稿>
```

如果结论可以继续：

```text
请按文昌·诊文的最小修改建议，先改开头、结构和结尾。

不要大幅改变主题。
不要新增未验证事实。
输出修改后正文和修改说明。
```
