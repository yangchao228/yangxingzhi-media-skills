# 示例：多平台分发资产

## 输入

```text
请把这篇公众号文章拆成知乎和小红书分发资产。

主题：AI 时代，个人为什么需要自己的内容系统
目标：
- 公众号保留完整判断文
- 知乎改成问题回答
- 小红书拆成 8 页图文卡片
```

## 知乎资产结构

```text
知乎问题：
普通人用 AI 写作，怎样避免每次都从零开始？

回答切口：
重点不在于收藏更多 prompt，而在于把自己的选题、采证、写作、诊断和发布检查固定下来。

回答结构：
1. 先说明临时 prompt 的问题
2. 解释内容系统的 4 个组成部分
3. 给出一个最小工作流
4. 说明哪些环节必须由人判断
5. 给 7 天练习建议
```

## 小红书卡片结构

```text
页 1 封面：
别只让 AI 帮你写稿
先搭一个内容系统

页 2：
很多人用 AI 写作的问题
不是不会写，而是每次都重新开始

页 3：
内容系统第一步
固定你的账号定位和读者

页 4：
内容系统第二步
选题先判断，别急着起稿

页 5：
内容系统第三步
采证要包含反向证据

页 6：
内容系统第四步
诊文比润色更重要

页 7：
内容系统第五步
发布包要包含标题、摘要、封面和转发文案

页 8：
真正的变化
把一次写作沉淀成下次可复用的资产
```

## 朋友圈文案

```text
AI 写作最容易被忽略的一点：不要每次都从零开始。

如果你的选题、采证、诊文、发布检查都能复用，AI 才会变成你的生产系统，而不只是临时帮你写一段话的工具。
```
