# 文昌 AI 内容生产工作流

文昌是一套给内容创作者使用的 AI 写作工作流。它把选题、采证、起稿、诊文、出刊检查、卡片化和归档拆成可复用步骤，让你不用每次从零写 prompt。

这套交付包适合已经会使用 Codex、Claude Code 或类似 AI 编程/写作环境的人。它提供的是内容生产方法和本地 skill 文件，不包含平台账号代运营、自动发布、流量保证或模型服务账号。

## 适合谁

- 想稳定做公众号、知乎、小红书内容，但流程总是散的人。
- 已经会用 AI 写作，但每次都靠临时 prompt 的人。
- 有主题、热点链接或初稿，需要判断能不能写、怎么写、值不值得发的人。
- 做个人 IP、技术内容、知识型内容、AI 内容号的小团队。
- 想把内容生产沉淀成可复用资产，而不只追一篇文章的人。

## 你会拿到什么

- 文昌核心 skill 包：总控、路由、采证、诊文、出刊检查。
- 内容平台辅助 skill：公众号写作、热点选题、知乎选题、小红书选题、图文卡片。
- 买家使用文档：安装、上手、验收、FAQ、售后边界。
- 复制即用模板：账号定位、主题成稿、初稿诊文、发布检查。
- 示例输出：主题到公众号发布包、初稿诊断、多平台分发资产。

## 能解决什么问题

- 从一个模糊主题收敛成可写选题。
- 从热点链接提炼自己的观点，不照搬原文。
- 给文章补事实、来源、反向证据和限制条件。
- 起草公众号正文，并保留平台风格和长期主线。
- 诊断初稿是否值得继续写，避免无效返工。
- 输出标题、摘要、标签、封面文案、朋友圈文案和小红书/知乎分发建议。

## 不承诺什么

- 不保证爆款、涨粉、变现结果。
- 不代运营账号，不替你自动发布。
- 不提供 ChatGPT、Claude、Codex 等模型账号。
- 不支持洗稿、侵权搬运、论文代写、违规营销。
- 不替你决定最终观点、事实判断和发布责任。

## 推荐上手路径

1. 先读 `INSTALL.md`，确认本地环境能使用 skill。
2. 打开 `USER_GUIDE.md`，按一个真实主题跑最小流程。
3. 复制 `templates/topic-to-article.md`，替换成自己的账号和主题。
4. 用 `examples/` 对照结果结构，确认输出是否跑偏。
5. 发布前使用 `templates/publish-check.md` 做最后检查。
