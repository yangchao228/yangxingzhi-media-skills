# STORM Research Prompt Templates

这些模板用于两类场景：

1. agent 内部执行 `storm-research`。
2. 生成给读者的可复制资料包，例如公众号后台回复领取。

## 模板 1：多视角扫描

```text
我正在研究这个主题：

[填写你的主题]

请不要直接给我结论。先从 5 个不同视角拆开看这个主题：

1. 实践者：每天实际处理这个问题的人。
2. 学者：长期研究这个领域的人。
3. 怀疑者：认为主流叙事存在问题的人。
4. 经济观察者：关注利益结构、成本、激励和商业模式的人。
5. 历史观察者：把当前问题放进更长周期里看的人。

请对每个视角输出：

- 这个视角最关心的问题。
- 它会支持的核心判断。
- 它会反对的常见说法。
- 它最可能掌握、但其他视角容易忽略的信息。
- 需要进一步查证的 3 个问题。

输出要求：

- 不要写成宣传稿。
- 不要急着综合。
- 不确定的地方请标注“需要查证”。
```

## 模板 2：矛盾地图

```text
基于上面的 5 个视角，请帮我画一张矛盾地图。

请输出：

1. 直接冲突
   - 哪些视角之间存在明显冲突？
   - 它们具体冲突在哪个判断上？

2. 证据强弱
   - 哪个判断证据最强？
   - 哪个判断证据最弱？
   - 弱在哪里：来源不足、样本不足、逻辑跳跃、利益相关，还是时间过期？

3. 共同承认
   - 哪些事实或判断是多个视角共同承认的？
   - 这些内容可以作为后续文章的稳定底座。

4. 关键盲点
   - 哪个重要问题没有任何视角充分讨论？
   - 这个盲点是否可能成为最有价值的选题？

5. 下一步查证
   - 如果只能继续查 5 个问题，应该查什么？
   - 每个问题建议优先找什么来源：论文、官方文档、财报、访谈、案例、数据集、媒体报道或用户反馈。

请用表格输出。
```

## 模板 3：研究简报

```text
请把上面的多视角扫描和矛盾地图，综合成一份研究简报。

简报面向：

[填写读者对象，例如：公众号读者 / 创作者 / 工程师 / 产品经理 / 投资人 / 家长]

请输出：

1. 一段话摘要
   - 100 到 150 字。
   - 讲清这个主题真正重要在哪里。

2. 5 个关键发现
   - 按可靠性从高到低排序。
   - 每个发现标注：支持它的视角、挑战它的视角、证据强度。

3. 一个隐藏连接
   - 哪两个看似无关的信息放在一起后，会产生新的判断？

4. 一个行动建议
   - 对 [填写你的角色] 来说，下一步最应该做什么？
   - 要具体到动作，不要停在态度。

5. 一个前沿问题
   - 哪个问题如果被回答，会显著改变我们对这个主题的理解？

输出要求：

- 请把“事实”“推断”“观点”分开。
- 没有来源支撑的判断请降级表述。
- 不要为了完整而补编材料。
```

## 模板 4：可信度评审

```text
请对刚才的研究简报做一次可信度评审。

请输出：

1. 可信度评分
   - 给每个关键发现打 1 到 10 分。
   - 说明扣分原因。

2. 最弱结论
   - 哪个结论最容易出错？
   - 需要补充什么来源才能提高可信度？

3. 偏见检查
   - 哪个视角被过度放大？
   - 哪个利益相关方的声音缺失？
   - 现在的结论是否过度依赖某一种来源？

4. 缺失视角
   - 是否需要加入第 6 个视角？
   - 例如：监管者、用户、普通从业者、失败案例、伦理研究者、供应链参与者。

5. 发布前修改建议
   - 哪些句子需要删掉？
   - 哪些句子需要降级？
   - 哪些事实必须人工核验？
   - 哪个结论可以作为文章主线？

请直接给出可执行修改建议。
```

## 公众号选题版

```text
我想围绕这个主题写一篇公众号文章：

[填写主题]

我的目标读者是：

[填写读者]

请按“多视角扫描 -> 矛盾地图 -> 研究简报 -> 可信度评审”的顺序帮我完成研究准备。

最后请输出：

1. 3 个最适合公众号的主切口。
2. 每个切口的标题候选。
3. 每个切口最强证据和最大风险。
4. 你推荐的切口，以及推荐理由。
5. 发布前必须人工核验的来源清单。

要求：

- 文章要有读者获得感。
- 不要只做热点搬运。
- 优先沉淀成方法、清单、模板或案例。
```

## 产品调研版

```text
我正在调研这个产品/赛道：

[填写产品或赛道]

请按 5 个视角拆解：

1. 用户：真实痛点和使用场景。
2. 产品经理：功能边界、用户路径、留存点。
3. 工程师：实现难点、成本、可靠性。
4. 商业负责人：付费动力、销售路径、利润结构。
5. 怀疑者：需求是否伪命题，替代方案是什么。

然后输出：

- 最大机会。
- 最大风险。
- 最需要验证的 5 个假设。
- 最小验证实验。
- 一页纸产品判断。
```

## 学习新领域版

```text
我想快速进入这个领域：

[填写领域]

请帮我用研究协议拆解：

1. 这个领域的核心问题是什么？
2. 初学者最容易误解什么？
3. 实践者真正每天处理的问题是什么？
4. 学术或专业证据支持哪些结论？
5. 有哪些常见观点被过度包装？
6. 最值得读的 10 个来源是什么？
7. 如果我只有 7 天，应该怎样安排学习路径？

输出要求：

- 按“先理解地图，再进入实践”的顺序组织。
- 给出每天的学习任务。
- 标注哪些内容必须动手做。
```
