# 《永恒的互补》公众号插图规划

## 目标

用少量概念插图，把 OpenAI 原文的核心隐喻和作者的个人延伸串成一条视觉线：

> 前沿智能提出想法 → 机构智能让想法落地 → 个人也需要找到自己的互补位置。

文章正文约 2,800 个非空白字符，建议配置 **1 张封面 + 5 张正文插图**。每张图只承担一个理解任务，不把文章做成数据图表合集。

## 视觉方向

参考 OpenAI《The Eternal Complement》的编辑插画气质，提取以下规则：

- 用概念隐喻表达抽象观点，少画写实场景。
- 画面保持一个主主体，使用明显的尺度对比：小人物 / 小石块，对应巨大系统 / 宇宙 / 机构网络。
- 留白充足，构图安静，有一点未知感和未来感。
- 采用克制的编辑色彩：深墨蓝、炭黑、暖米白、赭石、低饱和蓝绿，可用少量橙红作为焦点。
- 以暖象牙色手工纸、纸雕 / 拼贴、深靛蓝蓝图线稿为基础，加入微型模型式的真实物体阴影、少量水彩 / 炭笔痕迹和哑金、赭橙点缀。
- 不在图片里放长段中文或数据表；标题、图注和数字放在正文排版层。
- 不画拟人化机器人笑脸、赛博朋克城市、发光代码雨或“AI 大脑”库存图。
- 不复制 OpenAI 的具体构图和资产，借鉴其编辑感、纸面材料、细线连接、尺度反差和留白，形成自己的视觉系统。

后续如果进入生图阶段，每张图都应使用同一套色板、纸张质感、线条粗细和光照方向，保证像同一篇文章里的系列作品。

## 插图位置与内容

### 0. 封面：采石场与星辰

**放置位置**：文章封面，不插入正文。

**要表达的内容**：标题的核心反差——上方是抽象的星体、公式和巨大蓝图，下方是一块块石头、细小的人和漫长的路径。画面中心留出一条从“想法”通往“现实”的断裂桥面。

**构图**：横向宽幅；上半部轻、空、远，下半部重、密、具体；不要出现十亿个人物。

**建议图注**：十亿个爱因斯坦，也仍然需要一座能把石头运到现场的文明。

**Alt 文本**：星体与巨大蓝图悬在上方，许多细小的人和石块在下方铺设通往现实的道路。

### 可选图：首屏思想走到宇宙，双手仍在地面

**放置位置**：本轮正文暂不插入；如果后续觉得首屏需要视觉停顿，再作为备选图使用。

**要表达的内容**：原文的首个反差：人类的方程和望远镜已经触及宇宙早期，人的身体却没有走出月球。

**构图**：左下角是一只握着简陋望远镜的手，望远镜的细线延伸到右上方的星系和早期宇宙；地面上的手很小，远处的宇宙很大。不要画成科普海报。

**建议图注**：思想可以越过宇宙，身体和组织仍然要从地面出发。

**Alt 文本**：地面上一只手通过简陋望远镜望向遥远星系，细线连接着地面与宇宙。

### 2. 中段插图：从一根望远镜到一整套文明

**放置位置**：韦布望远镜事实段之后、Bloom 数据之前，用来先钉住“从个人工具到文明系统”的尺度跃迁。

**要表达的内容**：伽利略的少量工具与韦布背后的全球组织系统形成尺度对比。

**构图**：左侧是一架两片镜片的简陋望远镜；右侧是一座折叠展开的巨大观测装置，背后连接许多工厂、实验室、运输节点和细线网络。右侧不能画成真实工程图，重点是“一个人”到“一个文明”的尺度跃迁。

**建议图注**：看得更远，调用的互补能力也越来越多。

**Alt 文本**：左侧是一架手持望远镜，右侧是一座由工厂、实验室和运输节点共同支撑的巨大观测装置。

### 3. 中段插图：天才画纪念碑，机构搬石头

**放置位置**：institutional intelligence 段落之后、标题“AI 越强，先被派去做杂活”之前。

**要表达的内容**：institutional intelligence 不是抽象口号，而是一串正确的局部行动。

**构图**：上方是一张悬浮的纪念碑蓝图，下方是一条由石块、账本、审批印章、工具箱和运输轨道组成的流水线。人物保持很小，分散在不同环节；不要做成企业组织架构图。

**建议图注**：纪念碑的图纸很重要，石头也要一块块砌上去。

**Alt 文本**：悬浮的纪念碑蓝图下方，细小的人沿着石块、账本、工具和运输轨道协作。

### 4. 中段插图：一个人能启动，闭环仍然缺口

**放置位置**：OPC 段落之后。

**要表达的内容**：个人技术能力可以搭出系统，却未必天然拥有资源、销售、客户关系和交付能力。

**构图**：左侧是一座由代码、工具和齿轮组成的高塔；右侧是由客户、资源、交付和反馈节点组成的另一座塔；两者之间缺一段桥，几个人正在补桥。不要把人物画成“成功团队合影”。

**建议图注**：个人可以先把一座塔搭起来，闭环需要另一座塔来接住它。

**Alt 文本**：由工具和齿轮组成的技术高塔，与由客户、资源和反馈节点组成的另一座高塔之间缺少连接。

### 5. 中段插图：选题变多以后，真正难的是取舍

**放置位置**：选题经历段落之后。

**要表达的内容**：AI 让执行更便宜，取舍判断（taste）变成新的稀缺环节。

**构图**：画面中心是一个安静的人或小小的指南针，周围展开许多半透明的门、卡片、道路和未完成的物件；只有一条路径被轻微照亮。不要画焦虑、加班或时间管理场景。

**建议图注**：选项越来越多，值得继续的方向仍然需要有人挑出来。

**Alt 文本**：许多半透明的道路和项目围绕一个小小的指南针展开，只有一条路径被微光照亮。

### 6. 后段插图：深度、宽度，以及人的独特方向

**放置位置**：深度 / 宽度段落之后、人的好奇心之前。

**要表达的内容**：深度文明和宽度文明是两条可能路径；人的不同方向留在画面里。人的好奇心与个人异议由紧接着的文字承接，不让一张图同时承担两层论点。

**构图**：同一画面左右分叉。左侧向内收束为安静的深井、实验室和少量精准光束；右侧向外铺开为工厂、能源、轨道和缓慢扩张的星际结构。画面底部保留几个方向不同的小人物或小光点，表示人不只有一种角色。

**建议图注**：有些问题可以靠更深的思考推进，有些问题必须等待现实完成它的部分。

**Alt 文本**：画面向左右分叉，左侧是安静而深入的实验空间，右侧是缓慢扩张的工厂、能源和星际结构。

## 排版建议

- 封面之后，正文每 450–600 字出现一张图，避免连续两屏文字。
- 正文图统一横向 3:2；封面使用 16:9 或公众号封面裁切比例，先保留 2400px 以上母版。
- 图片上下各留一行图注，图注只解释隐喻，不重复正文段落。
- 图中不放标题、数据和长句；数字与来源留在正文。
- 第 2 张和第 3 张不要同时使用“望远镜 + 石块”的完全相同构图：前者讲规模，后者讲协作链。
- 第 4 张和第 5 张要保持人物很小，避免把文章重新画成个人效率故事。

## 生图执行顺序

1. 先做封面、韦布尺度跃迁图和“天才 / 机构”图，确认系列色板和质感。
2. 再做 OPC 互补、taste 取舍和深度 / 宽度分叉图；首屏宇宙反差图暂不生成。
3. 完成后统一检查：主体是否清楚、是否出现错误文字、是否过度像信息图、是否仍能在缩略图里看出隐喻。
4. 图片生成和版式确认通过后，再决定是否生成公众号上传版；本规划不包含上传或发布授权。
