# AI Distribution｜研究与事实依据

核验日期：2026-10-02（Asia/Shanghai）。用途：公众号长文。核心判断分为 FACT/EXTERNAL、ANALYSIS/INFERENCE 和 PLAN/TARGET，没有独立实验结果时不声称获客、转化或收入改善。

## 研究结论

- 适合继续写作：是。
- 主线：搜索时代争夺结果页位置；AI 参与决策后，企业可能需要进入“理解—发现—推荐—决策—行动”链路。
- GEO：写成生成式引擎回答中的内容可见性，不写成万能获客方法。
- AI Distribution：本文作者定义的研究框架，不是 OpenAI 官方产品名或标准化指标。
- 商业落点：AI 能否成为新的获客渠道仍需实验验证。

## 一手来源

1. [OpenAI DevDay 2026 Recap](https://openai.com/index/devday-2026-recap/)：20+ 公告；ChatGPT 作为人与 Agent 协作的共享界面；Agents API、Computer use、Plugin Extensions、MCP Events、Space 等能力与边界。
2. [OpenAI Plugin Extensions 文档](https://developers.openai.com/plugins/build/extensions)：插件可进入侧栏、对话面板和文件查看器；发现、排序和推荐机制持续调整。
3. [MCP 官方简介](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro)：连接 AI 应用与外部数据、工具和工作流的开放标准。
4. [Google Search Central：AI features and your website](https://developers.google.com/search/docs/appearance/ai-features)：现有 SEO 基础仍适用于 AI Overviews 和 AI Mode，没有额外特殊文件或专用标记可以保证出现。
5. [Generative Engine Optimization 论文](https://arxiv.org/abs/2311.09735)：GEO 作为提升生成式引擎回答中内容可见性的研究术语；论文实验结果不外推为普遍获客效果。

## 关键事实

- DevDay 2026 官方回顾发布于 2026-09-29；OpenAI 将本次发布描述为覆盖 ChatGPT、Codex、模型和新的工作方式。
- Agents API 的 Computer use、tool search、tool calling 和 context compaction 具有明确产品边界，不能写成所有用户都能无条件调用。
- Plugin Extensions 的产品入口与插件发现机制可支撑“能力入口在增加”的观察，但不能证明某个品牌会获得推荐或流量。
- MCP 是开放标准，不属于 OpenAI 2026 独有能力。

## 反向证据与限制

- AI 被提及不等于被推荐，被推荐不等于被选择，被选择也不等于 Lead、Sales 或 Revenue。
- 用户越来越直接向 AI 提问、AI 会替用户完成比较和行动，属于本文场景假设或趋势判断，不能写成普遍事实。
- China Clearly 与旅行 Prompt 是拟开展的研究实验，文章不呈现结果，不冒充已经获得推荐或成交。
- 单次 Prompt 会受模型、时间、地区、上下文、来源和随机性影响；实验需要重复采样并记录条件。
- “SEO → GEO → AI Distribution → AI Acquisition → AI Commerce”是可能的商业演进路径，不是已验证的行业标准。

## 研究简报

隐藏连接：执行能力变得更容易调用后，企业的数字资产需要从网页与内容扩展到实体、产品、结构化信息、工具、接口与行动；但每一步都必须连接到可验证的商业结果。

行动建议：先选一个输入清楚、结果可检查的海外获客场景，重复测试 AI 对品牌的理解、发现、推荐、决策与行动，再把结果与真实表单、销售和成交数据连接。

前沿问题：当 AI 替用户完成一次选择，企业怎样被发现、被验证、被调用，并对结果负责？
