# AI Agent 系统设计权：小红书图文卡片包

## 内容诊断

- 核心主题：AI Agent 从回答者变成行动者后，人必须设计目标、权限、反馈和责任边界。
- 最强传播角度：别急着追求全自动，先学会管住 Agent。
- 目标受众：AI 实践者、知识工作者、工程师、正在尝试自动化工作流的人。
- 封面冲突点：Agent 越强，人越不能只当提示词操作者。
- 推荐风格：极简轻科技风。理由：主题偏方法论和系统设计，适合清晰、专业、可收藏的视觉表达。
- 推荐页数：8 张。理由：原文既有事件入口，也有方法清单；8 张能保留冲突、事实、判断和可执行边界，阅读压力不高。

## 逐页文案

### 1. 封面

- 页面标题：Agent 时代，人要夺回系统设计权
- 页面正文：AI 从回答者变成行动者以后，真正稀缺的能力，是知道边界该放在哪里。
- 关键词：Agent、系统设计权、Human3.0
- 推荐元素：抽象小镇、路径线、控制台、边界框
- 呈现形式：大标题 + 一句钩子 + 品牌脚注

### 2. 共鸣页

- 页面标题：AI 已经不只会回答
- 页面正文：它开始接工具、跑流程、连系统、做决策建议。风险也从“答错了”升级成“行动跑偏了”。
- 关键词：回答者、行动者、流程
- 推荐元素：聊天框变成流程图
- 呈现形式：三段递进

### 3. 事件页

- 页面标题：虚拟小镇给了一个警报
- 页面正文：40+ 地点、120+ 工具、三套记忆、能量压力、治理投票。Agent 被放进了一个会持续塑形它的世界。
- 关键词：Emergence World、长期自治、压力测试
- 推荐元素：小镇地图、工具箱、能量条
- 呈现形式：事实卡 + 指标条

### 4. 误读页

- 页面标题：别急着给模型贴标签
- 页面正文：犯罪少不等于系统健康；产出多不等于边界稳定；高度一致也可能意味着缺少真实分歧。
- 关键词：模型排行、单指标误判、反向证据
- 推荐元素：三个警示标记
- 呈现形式：三条误判对照

### 5. 观点页

- 页面标题：你给 AI 什么系统，它就长出什么行为
- 页面正文：目标、工具、激励、记忆、同伴环境、权限边界，会共同塑造 Agent 的长期行为。
- 关键词：目标、工具、激励、记忆、边界
- 推荐元素：六边形系统图
- 呈现形式：中心观点 + 六个节点

### 6. 方法页

- 页面标题：Human3.0 要上移一层
- 页面正文：别只做提示词操作者。人要定义目标、设置边界、检查质量、承担责任、沉淀资产。
- 关键词：认知主权、系统设计、数字资产
- 推荐元素：人站在流程控制台前
- 呈现形式：五级阶梯

### 7. 清单页

- 页面标题：用 Agent 前，先守住 7 个边界
- 页面正文：目标、工具、证据、阶段、责任、记忆、资产。少一个边界，自动化就多一分失控成本。
- 关键词：七个边界、自动化、检查清单
- 推荐元素：可勾选 checklist
- 呈现形式：7 项清单

### 8. CTA 页

- 页面标题：先写一份 Agent 行动合同
- 页面正文：这周挑一个真实任务，写清楚目标、权限、暂停点、验收标准和沉淀资产。别急着全自动。
- 关键词：行动合同、暂停点、资产沉淀
- 推荐元素：合同纸、签名线、收藏标记
- 呈现形式：行动建议 + 收藏引导

## 统一视觉规范

- 风格模式：极简轻科技风，带少量贴纸化图标。
- 色彩方案：墨黑 `#111827`、电蓝 `#2563EB`、青绿 `#14B8A6`、珊瑚红 `#F9735B`、暖白 `#F8FAFC`、淡黄 `#FEF3C7`。
- 背景方案：浅色网格、轻微径向光、抽象小镇线稿、流程节点。
- 字体层级：标题 42-58px，副标题 24-30px，正文 24-28px，辅助信息 18-20px。
- 固定组件：左上角 `AI生命克劳德`，右上角页码，底部价值词 `更早发现 / 更准判断 / 更快行动`。
- 页面版式：每页只讲一个核心点；标题不超过两行；正文短句断行；重要词用色块或描边强调。
- 风格硬约束：不要末日废墟感，不做模型粉黑，不把实验写成模型善恶排名。
