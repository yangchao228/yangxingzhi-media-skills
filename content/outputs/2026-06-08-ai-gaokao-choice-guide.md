# AI 志愿填报三张表使用指南

## 使用前先看

这个资料包不是让 AI 替你报学校。

它的用途是：用 AI 协助家庭做三张表，把规则查清，把孩子问清，把家庭底线摊清。最后是否填报某个院校专业组，仍然要回到本省考试院、教育部阳光高考平台、高校招生章程和高校招生办核验。

不要把 AI 输出当最终依据。尤其不要让 AI 凭空生成“2026 年招生计划”“今年录取概率”“保证能上”等结论。AI 可以整理、追问、查漏、生成咨询问题，但不能替代官方信息和家庭判断。

## 一句话流程

先做信息表，再做孩子表，再做家庭资源表。三张表做完以后，再让 AI 整理候选方向、反查风险、生成招生办咨询问题。

建议安排一次 60 分钟家庭会议：

1. 家长先用 15 分钟整理信息表初稿。
2. 孩子用 20 分钟回答孩子表问题。
3. 全家用 15 分钟填写家庭资源表。
4. 最后用 10 分钟让 AI 汇总三张表，列出待核验清单。

## 第一张表：信息表

信息表解决事实问题：规则、数据、限制条件有没有查准。

这一张可以让 AI 做资料助理，但必须给 AI 明确边界：只整理你提供的信息，只列核验项，不编数据。

| 项目 | 当前信息 | 来源 | 待核验问题 | 是否已确认 |
| --- | --- | --- | --- | --- |
| 省份 / 批次 |  | 本省考试院 | 今年批次和志愿规则是否已发布 |  |
| 位次 / 分数 |  | 本省考试院 | 是否使用同科类同批次位次 |  |
| 院校专业组 |  | 本省招生计划 | 专业组内是否含不能接受专业 |  |
| 学费 / 校区 |  | 招生章程 / 学校官网 | 是否有中外合作、分校区、住宿差异 |  |
| 体检 / 语种 / 单科限制 |  | 招生章程 | 是否影响录取或专业调剂 |  |
| 转专业政策 |  | 学校官网 / 招生办 | 条件、比例、时间、失败后路径 |  |

### Prompt 1：列信息核验清单

```text
我正在做高考志愿填报的信息表。

请不要推荐学校，也不要编造招生数据。

请根据高考志愿填报常见风险，帮我列一张信息核验清单。清单包括：要查什么、去哪里查、查不到会有什么风险、是否需要打招生办电话。

优先核验：本省招生计划、院校专业组、招生章程、学费、校区、体检限制、语种限制、单科成绩要求、转专业政策。
```

### Prompt 2：整理我粘贴的官方信息

```text
下面是我从本省考试院、阳光高考、高校招生章程或学校官网复制来的信息。

请只整理我提供的内容，不要补充未出现的数据。

请整理成表格，列出：已确认信息、来源、可能影响的志愿选择、仍需人工核验的问题。

如果某项信息不完整，请标注“待核验”，不要自行推断。
```

## 第二张表：孩子表

孩子表解决偏好问题：孩子能接受什么、排斥什么、愿意为什么承担代价。

这一张不能交给 AI 代填。AI 适合做提问助理，帮助父母把问题问具体。

| 问题 | 孩子回答 | 确定程度 | 会影响什么选择 |
| --- | --- | --- | --- |
| 最不能接受的三类学习内容 |  | 高 / 中 / 低 | 专业方向 |
| 愿意长期面对什么对象 |  | 高 / 中 / 低 | 医学、师范、工科、财经等 |
| 能接受离家多远 |  | 高 / 中 / 低 | 城市 / 省份 |
| 更看重城市、学校、专业还是就业 |  | 高 / 中 / 低 | 志愿排序 |
| 能否接受读研、转专业失败、复读风险 |  | 高 / 中 / 低 | 专业和学校选择 |

### Prompt 3：让 AI 生成提问清单

```text
我想让孩子参与高考志愿填报。

请先不要推荐学校。

请生成 20 个适合家长和孩子一起讨论的问题，帮助我们弄清楚孩子的专业偏好、排斥项、城市偏好、风险承受能力、读研意愿和就业期待。

每个问题后面请写明：这个回答会影响哪些志愿选择。
```

### Prompt 4：整理孩子回答

```text
下面是孩子对志愿问题的回答。

请整理成孩子表，分成四类：已确认偏好、不确定偏好、明确不能接受、需要进一步了解的专业或城市。

不要替孩子下结论。遇到模糊回答，请生成后续追问。
```

## 第三张表：家庭资源表

家庭资源表解决约束问题：家庭能托住什么，不能接受什么，试错空间有多大。

这一张容易尴尬，但越早谈越好。AI 适合做会议提纲，把难开口的问题先列出来。

| 项目 | 家庭当前答案 | 底线 | 需要继续讨论 |
| --- | --- | --- | --- |
| 学费上限 |  |  |  |
| 是否接受民办 / 中外合作 |  |  |  |
| 是否支持读研 / 出国 / 二战 |  |  |  |
| 是否需要尽早就业 |  |  |  |
| 转专业失败能否承受 |  |  |  |
| 父母最在意的底线 |  |  |  |
| 孩子最在意的底线 |  |  |  |

### Prompt 5：生成家庭会议提纲

```text
请帮我们准备一次高考志愿家庭会议。

请先整理家庭资源表，暂时不推荐学校。

请列出必须讨论的问题，覆盖：学费上限、民办和中外合作、读研支持、出国可能、是否需要尽早就业、转专业失败后的调整、离家距离、父母底线、孩子底线。

每个问题后面请说明：如果不提前讨论，填志愿时可能出现什么冲突。
```

## 三张表之后做什么

三张表不是终点。它们只是把家庭决策依据整理出来。

接下来走 6 步：

1. 汇总成一份决策依据：已确认事实、孩子偏好、家庭约束、待核验问题。
2. 先划边界：可接受城市、可接受专业、绝对不碰的专业、学费上限、是否接受民办和中外合作。
3. 再生成候选清单：把本省当年招生计划、位次、选科和三张表内容提供给 AI，让它辅助整理候选方向。
4. 让 AI 反向审查：检查数据过期、专业组调剂、校区、学费、体检、语种、单科成绩、家庭约束冲突。
5. 把高风险项变成招生办电话问题。
6. 全家一起排序：不只看录取把握，也看孩子愿不愿意、家庭托不托得住、风险能不能接受。

提交前，让孩子亲口说一遍：

```text
我选择这个方向，是因为……
我知道它的好处是……
我知道它的风险是……
如果未来发现不适合，我准备先这样调整……
```

## 三张表汇总后，再让 AI 查漏

三张表做完以后，再让 AI 协助整理，而不是一开始就让它报学校。

### Prompt 6：汇总三张表

```text
下面是我们整理好的信息表、孩子表和家庭资源表。

请帮我汇总成一份志愿决策依据。

要求：
1. 只使用我提供的信息；
2. 分成事实、偏好、约束、待核验四部分；
3. 标出冲突点，例如孩子偏好和家庭资源不一致；
4. 不要推荐具体学校。
```

### Prompt 7：反向检查志愿清单

```text
下面是我们暂定的志愿清单。

请站在反方角度检查风险。

重点检查：数据来源是否可靠、是否可能过期、专业组内是否含孩子不能接受的专业、是否有学费/校区/体检/语种/单科限制、是否过度押注热门专业、是否和家庭资源表冲突。

不确定的地方请标注“必须人工核验”。
```

### Prompt 8：生成招生办电话咨询问题

```text
请把下面的待核验项整理成给高校招生办的电话咨询问题。

要求问题具体、可直接照着问，不要含糊。

重点覆盖：校区、学费、转专业条件、专业组内调剂、体检限制、语种限制、单科成绩要求。
```

## 人工核验清单

AI 输出后，至少人工核验这些项目：

- 本省考试院发布的当年招生计划和志愿填报规则。
- 当年一分一段表、投档线、位次口径。
- 高校招生章程。
- 院校专业组内包含哪些专业。
- 是否有不能接受的调剂方向。
- 学费、校区、住宿、培养模式。
- 体检、语种、单科成绩要求。
- 转专业政策的条件、比例、时间。
- 高校招生办电话确认过的特殊问题。

## 常见错误用法

错误 1：直接问 AI “帮我推荐学校”。

修正：先让 AI 帮你做三张表，再检查候选清单。

错误 2：让 AI 生成当年招生计划。

修正：当年招生计划必须来自本省考试院或官方志愿系统，AI 只能整理你提供的内容。

错误 3：把商业工具的录取概率当结论。

修正：概率只能做参考，最终要结合位次、专业组、章程、调剂风险和家庭偏好。

错误 4：孩子只提供分数和一句“都可以”。

修正：至少让孩子回答孩子表里的排斥项、城市偏好、专业理解和风险承受问题。

错误 5：填报前才谈钱和底线。

修正：家庭资源表要提前做，学费、读研、转专业失败、离家距离都要摆到桌面上。

## 采证与修正依据

本指南做过以下核验，并据此修正了 prompt 和使用流程：

1. 教育部“阳光高考”平台已推出“阳光志愿”信息服务系统，官方口径强调免费公共服务和多维信息参考。因此指南建议优先使用官方平台和本省考试院信息，不让 AI 编造当年数据。来源：[教育部“阳光高考”平台开通“阳光志愿”信息服务系统](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202406/t20240617_1136235.html)、[阳光高考平台](https://gaokao.chsi.com.cn/?v=1)。
2. 教育部提醒考生和家长警惕“高价”志愿填报指导服务，所谓“内部大数据”通常来自公开渠道汇总。因此指南把“内部数据”“保证录取”“精准定位”列为风险词。来源：[教育部提醒考生及家长警惕“高价辅导”陷阱](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202406/t20240618_1136298.html)。
3. 人社部相关提示明确，“高考志愿规划师”未列入职业分类大典和国家职业资格目录。因此指南不建议把“证书权威”当选择咨询服务的依据。来源：[阳光高考：高考志愿规划师靠谱吗？](https://xz.chsi.com.cn/xz/zyts/202307/20230718/2293101239.html)。
4. 北京市市场监管局 2025 年曝光过“高考志愿规划师”速成培训违法广告案例，并提醒不要迷信天价志愿咨询。因此指南强调买咨询要买规则解释、信息核验、风险提示，不买确定性承诺。来源：[北京市市场监督管理局曝光台](https://scjgj.beijing.gov.cn/zwxx/scjgdt/202506/t20250626_4126259.html)。
5. HCI 研究发现，中国家庭使用 AI 辅助升学决策时，AI 工具往往由父母主导，学生参与有限，并容易聚焦即时分数结果，忽略长期职业目标。因此指南把孩子表单独列出，要求孩子亲自回答偏好、排斥项和代价问题。来源：[arXiv: From Score-Driven to Value-Sharing](https://arxiv.org/abs/2411.10280)。

## 最后提醒

AI 可以帮家庭看见更多信息，也可以让讨论更有结构。

志愿填报最终要回到家庭共同决策。规则要查准，孩子要参与，底线要摊开，最后再提交。
