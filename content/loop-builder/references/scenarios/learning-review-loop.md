# 学习复盘 Loop

## 定位

用于把阅读、课程、论文、工具探索、项目复盘转成长期知识资产。重点是让学习结果进入个人系统，而非只留下零散笔记。

适用对象：

- 读书笔记
- 课程学习
- 技术文档学习
- 论文或报告阅读
- 工具试用复盘
- 项目经验沉淀
- Human3.0 个人系统建设

## Loop 适配判断

- 结论：适合 Lifecycle Loop。
- 推荐主模式：Lifecycle Loop。
- 可组合模式：Human-in-the-Loop、Explore-Narrow。
- 暂缓进入执行的信号：
  - 输入材料还没有明确来源。
  - 用户只想要一次性摘要。
  - 学习目标无法落到行动、判断或资产。

## 最小 Loop 设计卡

| 字段 | 内容 |
|---|---|
| 目标 | 把一次学习输入转成可复用的知识资产和行动清单 |
| 输入 | 书、文章、课程、视频、论文、项目记录、用户笔记 |
| 状态 | `knowledge/<topic>/learning-loop-state.md` 或当前专题目录下的 `learning-state.md` |
| 执行者 | Intake Scout / Note Maker / Insight Checker / Asset Evaluator |
| 验收者 | 用户 + 输出清单 |
| 反馈信号 | 来源记录、核心概念、反例、行动项、可复用模板 |
| 停止规则 | 来源不足、只剩摘要、无法形成行动、用户未确认长期方向 |
| 人工确认节点 | 个人判断、公开分享、归档到长期系统、商业使用 |
| 禁止动作 | 不伪造已读内容，不替用户确认观点，不把摘要当成掌握 |

## 阶段流程

| 阶段 | 目标 | 产物 | 验收 |
| --- | --- | --- | --- |
| Intake | 明确学习输入和目标 | 来源清单、学习问题 | 来源可追溯 |
| Extract | 提取概念和结构 | 概念表、框架图 | 能复述 |
| Connect | 连接已有项目和内容 | 关联清单 | 有具体场景 |
| Apply | 转成行动或模板 | 行动清单、模板 | 可执行 |
| Review | 复盘是否进入系统 | 复盘记录、归档位置 | 用户确认 |

## Planner Prompt

```md
你是学习复盘 Loop 的 Planner，只负责设计学习路径。

输入：
- 学习主题：<topic>
- 输入材料：<materials>
- 用户目标：<goal>
- 当前项目或内容主线：<context>

请输出：
1. 是否适合进入学习复盘 Loop。
2. 本轮学习问题。
3. 建议读取或处理顺序。
4. 应沉淀成哪些资产。
5. 哪些判断必须由用户确认。
6. 下一步交给 Maker 的最小任务。
```

## Maker Prompt

```md
你是学习复盘 Loop 的 Maker，只处理已确认的输入材料。

任务：
把本轮学习输入转成结构化笔记和行动清单。

要求：
1. 标明来源和位置。
2. 区分原文观点、你的解释和用户可行动作。
3. 不伪造未读取材料。
4. 不把未经验证的观点写成用户立场。
5. 输出可沉淀资产。

输出：
- 核心概念
- 关键依据
- 反例或限制
- 可应用场景
- 行动清单
- 归档建议
```

## Checker Prompt

```md
你是学习复盘 Loop 的 Checker，只负责判断学习产物是否可用。

请检查：
1. 来源是否可追溯。
2. 是否区分原文、解释和用户判断。
3. 是否只有摘要，缺少行动或资产。
4. 是否能服务 Human3.0 的个人系统建设。
5. 是否需要用户确认公开分享或归档。

输出：
- 通过 / 不通过 / 需要用户确认
- 证据
- 缺口
- 下一步建议
```

## Evaluator Prompt

```md
你是学习复盘 Loop 的 Evaluator，负责判断是否继续学习、实践或沉淀。

输入：
- State file
- Maker 输出
- Checker 输出
- 用户目标

请判断：
1. 本轮是否完成。
2. 是否需要继续读、做实验或写文章。
3. 是否可以沉淀为模板、Skill、AGENTS.md 规则或书稿素材。
4. 哪些观点需要用户确认。

输出：
- 决策：完成 / 继续学习 / 进入实践 / 等待用户确认
- 原因
- 下一步
- 可沉淀资产
```

## 断路器

- 输入材料没有来源。
- Maker 声称读过未提供或未读取的内容。
- 输出只有摘要，没有行动、判断或资产。
- 把模型解释写成用户观点。
- 公开分享、归档或商业使用没有用户确认。
- 连续两轮没有产生可复用资产。

## 第一次运行建议

从一个具体材料开始，限制范围：

```md
帮我把 <文章/课程/书的章节> 做成学习复盘 Loop。
本轮只处理这一个材料，输出概念表、行动清单和可沉淀资产，不写公开文章。
```

## 资产沉淀

- 概念表：进入知识库。
- 行动清单：进入任务系统。
- 复盘结论：进入个人规则或 AGENTS.md。
- 成熟案例：进入内容素材库。
- 稳定流程：升级为 Skill 或模板。
