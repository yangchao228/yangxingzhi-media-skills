# 内容生产 Loop

## 定位

用于把选题、采证、起稿、诊文、出刊、归档做成可复用的内容生产系统。

适用对象：

- 公众号系列
- 知乎长文
- 小红书图文
- 电子书素材
- Human3.0 内容素材库
- 文昌链路中的选题、采证、诊文、发布检查和归档

## Loop 适配判断

- 结论：通常适合 Loop，但最终选题、发布、入书和商业包装需要用户确认。
- 推荐主模式：Explore-Narrow。
- 可组合模式：Human-in-the-Loop、Lifecycle Loop。
- 暂缓进入执行的信号：
  - 主题还没有边界。
  - 没有目标平台。
  - 缺少事实来源或真实经验。
  - 用户还没有确认是否发布。

## 最小 Loop 设计卡

| 字段 | 内容 |
|---|---|
| 目标 | 把一个内容主题推进到可发布稿或可归档素材 |
| 输入 | 用户想法、已有草稿、素材链接、目标平台、历史文章 |
| 状态 | `content/<series>/content-loop-state.md` 或当前专题目录下的 `TODO.md` |
| 执行者 | Topic Scout / Researcher / Draft Maker / Review Checker / Archive Evaluator |
| 验收者 | 用户 + 文昌检查链路 |
| 反馈信号 | 选题评分、来源质量、草稿结构、发布检查、用户确认 |
| 停止规则 | 选题不成立、证据不足、草稿不服务账号主线、用户未确认发布 |
| 人工确认节点 | 最终选题、标题、发布、归档、商业包装 |
| 禁止动作 | 不替用户最终发布，不编造来源，不替用户确认入书或上架 |

## 阶段流程

| 阶段 | 目标 | 产物 | 可用链路 |
| --- | --- | --- | --- |
| 探脉 | 找到值得写的候选 | 选题池、评分表 | `wenchang-router` / 热点选题 skill |
| 定题 | 收敛成一个切口 | 题目、读者、承诺 | 选题诊断 |
| 采证 | 补事实和反向证据 | 来源包、引用点、风险点 | `wenchang-research` |
| 起稿 | 生成可诊断初稿 | 正文草稿 | 写作 skill |
| 诊文 | 判断是否能发 | 诊断报告、最小修改建议 | `wenchang-review` |
| 出刊 | 准备发布资产 | 标题、摘要、封面建议、分发文案 | `wenchang-publish-check` |
| 归档 | 沉淀长期资产 | 素材库条目、成书候选 | `human3-book-guardian` |

## Planner Prompt

```md
你是内容生产 Loop 的 Planner，只做选题判断和流程设计。

任务：
把以下内容目标设计成可验证、可停止、可归档的内容生产 Loop。

输入：
- 主题：<topic>
- 目标平台：<platform>
- 已有素材：<materials>
- 账号主线：Human3.0 / AI生命克劳德 / 其他

请输出：
1. 这个主题是否适合进入内容生产 Loop。
2. 推荐阶段：探脉、定题、采证、起稿、诊文、出刊或归档。
3. 3 到 5 个候选切口。
4. 每个切口的读者获得感、证据需求和长期资产价值。
5. 下一步该交给哪个角色。
6. 必须由用户确认的节点。
```

## Maker Prompt

```md
你是内容生产 Loop 的 Maker，只完成当前阶段的最小产物。

当前阶段：
<探脉 / 定题 / 采证 / 起稿 / 诊文 / 出刊 / 归档>

输入：
- 状态文件：<state path>
- 允许读取：<paths or materials>
- 允许产出：<output path>

执行要求：
1. 只处理当前阶段。
2. 不编造来源、数据或用户经历。
3. 不替用户做最终发布、入书或商业包装决定。
4. 输出要能交给 Checker 验收。

输出：
- 本阶段产物
- 证据或依据
- 风险点
- 需要用户确认的问题
```

## Checker Prompt

```md
你是内容生产 Loop 的 Checker，只检查质量和边界。

请检查：
1. 当前阶段产物是否满足目标平台。
2. 是否有明确读者获得感。
3. 是否有事实、案例或用户经验支撑。
4. 是否出现无来源强断言。
5. 是否保留用户对标题、发布、归档和商业包装的确认权。
6. 是否适合进入下一阶段。

输出：
- 通过 / 不通过 / 需要用户确认
- 主要证据
- 最大风险
- 下一步建议
```

## Evaluator Prompt

```md
你是内容生产 Loop 的 Evaluator，负责判断本轮是否继续。

输入：
- State file
- Maker 输出
- Checker 输出
- 用户约束

请判断：
1. 是否继续下一阶段。
2. 是否回到采证或诊文。
3. 是否停止该主题。
4. 是否沉淀为素材库、系列选题或电子书章节。

输出：
- 决策：继续 / 停止 / 等待用户确认 / 转为素材
- 原因
- 下一步
- 可沉淀资产
```

## 断路器

- 关键事实没有来源。
- 文章承诺超过证据能支撑的范围。
- 选题只追热点，无法沉淀为长期资产。
- 标题和正文承诺不一致。
- 输出开始替用户确认发布、入书或商业包装。
- 用户明确表示暂停或换方向。

## 第一次运行建议

从一个已发布或即将发布的公众号专题开始。先只做“选题池 + 决策表 + 归档建议”，不要直接生成长文。

推荐最小任务：

```md
帮我把 <主题> 做成内容生产 Loop。
目标平台：公众号。
已有素材：<文件或链接>。
本轮只需要选题池、决策表和下一步，不写正文。
```

## 资产沉淀

- 好选题：进入系列选题库。
- 好案例：进入 Human3.0 素材库。
- 好模板：进入文昌 Skill 或模板库。
- 失败题：进入失败报告，记录为什么不值得写。
