# 专用 Loop Agent 包

本文件用于生成可反复运行的任务专属 Loop Agent。`loop-builder` 负责生成 Agent 包，不负责长期运行，也不把业务数据写回 `loop-builder`。

## 适用场景

用户出现以下意图时使用：

- 后续还要反复跑这个任务。
- 把某个内容专题、项目维护、学习复盘或数据复盘做成专用 Agent。
- 需要把业务经验沉淀到专用 Agent，而不是污染通用 Skill。
- 需要判断某条经验是否值得抽象回 `loop-builder`。

## 三层边界

| 层级 | 放什么 | 不放什么 |
| --- | --- | --- |
| `loop-builder` | 通用 Loop 设计方法、模式选择、模板、边界规则 | 具体业务数据、具体账号指标、单一项目阈值 |
| 专用 Loop Agent | 任务职责、输入 schema、运行协议、专用判断规则、候选通用规则 | 自动修改 `loop-builder` 的动作 |
| 业务目录 | 原始数据、运行记录、诊断结果、用户确认记录 | 通用 Skill 的默认规则 |

## 默认文件包

生成专用 Agent 时，默认输出以下文件建议：

```text
<业务目录>/
  <任务名>-LoopAgent.md
  <任务名>-state.md
  <任务名>-input-schema.md
  <任务名>-run-log.md
  <任务名>-rule-candidates.md
```

如果用户只要求诊断档，不生成这些文件，只给出建议路径。

5. 更新 run log。

## 输出要求

生成专用 Agent 包时，必须写清：

- 专用 Agent 放在哪个业务目录。
- 业务数据存在哪里。
- 哪些规则只属于专用 Agent。
- 哪些规则只是候选通用规则。
- 候选规则升级必须由用户确认。
