# 01 公众号正文插图细化：Agent 会不会自己变强

状态：插图结构已完成，默认进入 `../image-prompts/01-panorama-prompts.md` 手动出图
风格：公众号正文插图固定 16:9，极简轻科技风，清晰、克制、适合正文阅读

## 图 01 自改进三层定义

- 放置段落：正文“多试几次，不等于会成长”之后。
- 图片比例：16:9，公众号正文插图。
- 图形类型：横向三段递进流程。
- 主标题：自改进的三层
- 副标题：从当前任务修正，到改变下一次行为
- 内容：同一任务做得更好 / 从错误中学习 / 改变下一次行为。
- 作用：帮读者区分“多跑几次”和“经验写回系统”。

## 图 02 Agent 自我改进的 5 个条件

- 放置段落：正文“第一个条件：结果必须可验证”之后。
- 图片比例：16:9，公众号正文插图。
- 图形类型：中心节点 + 五条件环绕图。
- 主标题：Agent 想变强，先看 5 个条件
- 副标题：缺一项，系统就容易漂移
- 内容：可验证任务、结构化反馈、持久化记忆、外环复盘、人工审核。
- 作用：把文章主框架视觉化，降低读者后续阅读成本。

## 图 03 4 类真实入口

- 放置段落：EvoSkill / Karpathy 案例段落后。
- 图片比例：16:9，公众号正文插图。
- 图形类型：四宫格案例矩阵。
- 主标题：自改进 Agent 的 4 类真实入口
- 副标题：先从可验证场景开始
- 内容：连续编码循环、失败轨迹提炼 Skill、自动实验研究、反馈日志 + 学习存储。
- 作用：把来源案例从资料列表转成方法地图。

## 图 04 Agent 错题本 CTA 横图

- 放置段落：正文结尾 CTA 前。
- 图片比例：16:9，公众号正文插图。
- 图形类型：模板字段 + 评论引导。
- 主标题：先给 Agent 建一个错题本
- 副标题：失败要变成下一次能用的规则
- 内容：任务目标、预期结果、实际结果、验证证据、失败类型、下一次规则。
- 作用：把读者行动收束到“评论错题本，领取模板”。

## 和 3:4 贴图的关系

- 16:9 插图用于公众号正文阅读。
- 3:4 贴图用于收藏、转发、朋友圈、社群和跨平台复用。
- 同一个信息点可以有两套比例，发布公众号正文时优先使用 16:9。
