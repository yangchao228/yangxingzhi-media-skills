# 公众号贴图 / 插图 brief

公众号贴图和公众号插图是两类图。

- 公众号插图：默认 16:9 横图，适合放在正文中解释复杂机制、流程和模板。
- 公众号贴图：默认 3:4 信息卡，适合截图、收藏、转发、文末 CTA 和跨平台复用。

默认交付形式都是图片提示词，用户手动复制到 ChatGPT 出图。

## 公众号插图作用

- 正文里解释复杂机制和流程。
- 横向展示多节点关系、循环和对照。
- 降低长文阅读负担，让读者不用在段落里反复找关系。
- 比例默认 16:9，适合公众号正文宽度。

## 默认数量

正文插图每篇 2-4 张，比例固定为 16:9。

| 位置 | 图的作用 | 形式 |
| --- | --- | --- |
| 首屏后 | 把文章核心判断视觉化 | 16:9 判断图 / 总览图 |
| 讲机制时 | 降低理解成本 | 16:9 流程图 / 架构图 |
| 讲方法时 | 解释模板怎么用 | 16:9 checklist / 模板说明图 |
| 讲边界时 | 强化风险和停止条件 | 16:9 红线清单 / 决策图 |
| 文末 | 引导评论领取 | 16:9 CTA 横图 |

## 公众号贴图作用

- 贴图服务收藏、转发和跨平台复用。
- 贴图比例默认 3:4。
- 贴图可以复用到小红书图文、朋友圈、社群、资料领取页。
- 贴图不作为公众号正文插图的默认比例。

## 和小红书图文的区别

| 维度 | 公众号贴图 | 小红书图文 |
| --- | --- | --- |
| 依赖正文 | 可独立转发，弱依赖正文 | 独立成立 |
| 比例 | 3:4 | 3:4 |
| 信息密度 | 低到中 | 中到高 |
| 主要目标 | 帮助理解和截图 | 点击、收藏、转发 |
| 文案方式 | 关键词、关系、流程 | 独立标题和短正文 |
| 数量 | 3-5 张 | 7-9 张 |

## 视觉默认

- 公众号贴图固定 3:4。
- 公众号插图默认 16:9，正文发布优先使用。
- 不做复杂装饰，优先清晰的信息结构。
- 统一品牌：AI生命克劳德。
- 统一价值词：更早发现 / 更准判断 / 更快行动。
