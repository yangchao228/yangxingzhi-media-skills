## 核心判断

这个专题不写成“Agent 将自动进化”的趋势稿。更稳的主线是：

> Agent 变强的前提，是任务可验证、反馈可记录、规则可更新、更新可审核。

Loop Engineering 解决“如何让 Agent 持续执行”。自我改进系列继续往后一层，解决“执行经验如何留下来，并在下一轮改变 Agent 的行为”。

## 每篇标准工作流

1. 更新 `source-pack.md`：事实、案例、反方、可引用数据、不能写死的存疑点。
2. 写公众号长文：形成完整论证和模板。
3. 设计公众号插图：默认 2-4 张，比例 16:9，服务正文阅读和机制理解。
4. 设计公众号贴图：默认 3-5 张，比例 3:4，服务截图、收藏、转发和评论领取。
5. 生成图片提示词：公众号贴图、公众号插图、小红书图文、视频封面和 B-roll 默认只输出提示词，用户手动到 ChatGPT 出图。
6. 拆小红书图文：默认 8 页，结构为封面、问题、判断、机制、案例、方法、边界、CTA。
7. 拆两条短视频：
   - 小红书视频：我为什么这么判断 + 你可以怎么做。
   - 抖音视频：一个反常识判断 + 一个例子 + 一个行动建议。
8. 发布后回收反馈：评论问题、收藏点、私信需求、争议点。

## 统一内容模板

### 公众号

- 标题偏判断和框架。
- 第一屏用具体场景或明确问题，不写泛背景。
- 主体必须有来源、反方、边界和一个可复制模板。
- 公众号正文插图默认 2-4 张，比例 16:9，分别承担概念解释、机制说明、流程展示或 CTA 引导。
- 公众号贴图是另一类图，默认 3:4，服务截图、收藏、转发和跨平台复用。
- 插图不复述正文段落，优先画关系、流程、表格和检查清单。
- 贴图默认交付 ChatGPT 图片提示词，不直接生成图片。
- 文末 CTA 统一引导：评论区领取“Agent 错题本 / Skill 审核表 / 自改进 Loop 模板”。

### 小红书图文

- 默认 8 页。
- 每页只放一个判断。
- 封面强调“可收藏”和“能立刻拿走”。
- 论文、工具和公司新闻只做支撑，不堆来源名。
- 默认生成逐页图片提示词，用户手动出图。

### 视频

- 固定结构：钩子 3 秒、判断 10 秒、案例 25 秒、方法 20 秒、收束 5 秒。
- 小红书视频可以更像个人经验复盘。
- 抖音视频开头必须更直接，前 3 秒给冲突。
- 每条视频只解决一个问题。
- 封面和 B-roll 默认只生成提示词。
