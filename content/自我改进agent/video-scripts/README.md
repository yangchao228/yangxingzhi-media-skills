# 短视频脚本

本目录维护小红书视频和抖音短视频脚本。默认采用低成本制作：屏录 + 字幕 + 旁白/轻口播，不强依赖真人出镜。

视频封面和 B-roll 画面默认只生成图片提示词，用户手动到 ChatGPT 出图。

## 平台差异

| 平台 | 目标 | 语气 | 结构 |
| --- | --- | --- | --- |
| 小红书视频 | 建信任 | 像个人复盘，保留方法细节 | 判断 + 为什么 + 怎么做 |
| 抖音视频 | 拿注意力 | 开头更直接，冲突更强 | 反常识 + 例子 + 行动建议 |

## 默认脚本结构

- 0-3 秒：钩子。
- 3-13 秒：核心判断。
- 13-38 秒：案例或机制。
- 38-58 秒：行动建议。
- 58-65 秒：收束和评论引导。

## 文件

- `script-briefs.md`：第一季每篇的两条视频脚本。
- `01-panorama-scripts.md`：第 01 篇小红书视频和抖音脚本细稿。
