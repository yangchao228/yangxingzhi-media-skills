## 核心判断

Agent 反复犯错时，优先补反馈系统和错题本，不要只换模型或放大自动化。

这条视频只讲一个判断：失败要留下来，才可能变成下一次能用的经验。

## 默认旁白稿

建议时长：60-90 秒。

```text
你的 Agent 还在重复犯同一个错吗？

你提醒它开头别写大趋势，下次它又写。你提醒它处理中文路径前先核真实文件名，隔几天它又开始猜。

问题不一定是模型不够强，可能是失败没有留下来。

很多人讲自改进 Agent，好像多跑几轮就会自动变聪明。但多试几次，只是多试几次。真正有用的自改进，至少要让 Agent 知道三件事：结果对不对，错在哪里，下次该避开什么。

所以第一步别急着换模型，先建一个 Agent 错题本。

每次失败只记六项：任务目标、预期结果、实际结果、验证证据、失败类型、下一次规则。

一周后，再让 Agent 复盘重复错误，提出 Skill 或模板更新建议。合不合并，人来审。

失败留下来，才可能变成经验。

评论区留“错题本”，我整理模板。完整版文章放在公众号「AI生命克劳德」。
```
