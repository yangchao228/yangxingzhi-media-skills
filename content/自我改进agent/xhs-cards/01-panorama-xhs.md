### 主发布配文

很多人讲 Agent 自我改进，容易讲得很玄。

我更关心一个简单问题：它靠什么知道自己变好了？

如果没有可验证任务、结构化反馈、持久化记忆、外环复盘和人工审核，Agent 多跑几轮也只是多试几次。

普通人的第一步很简单：给 Agent 建一个错题本。失败要留下来，才能变成下一次能用的规则。

### 简短配文

Agent 想长记性，先别急着换模型。先把失败记录下来，变成它下次能读懂的规则。
