# 小红书图文卡片规划

本目录负责把公众号长文拆成可收藏的小红书信息卡。默认先做 8 页结构、逐页文案和图片提示词，不直接生成图片。

当前默认规则：只交付可复制到 ChatGPT 的图片提示词，用户手动出图。

## 默认结构

| 页码 | 类型 | 作用 |
| --- | --- | --- |
| 01 | 封面 | 强问题或反常识判断 |
| 02 | 共鸣页 | 读者正在遇到什么问题 |
| 03 | 核心判断 | 本篇最重要的一句话 |
| 04 | 机制页 | 图解概念或流程 |
| 05 | 案例页 | 放一个真实案例 |
| 06 | 方法页 | 给可执行步骤 |
| 07 | 边界页 | 告诉读者什么不能做 |
| 08 | CTA 页 | 引导收藏、评论领取模板 |

## 视觉默认

- 风格：极简轻科技风。
- 比例：3:4。
- 品牌：AI生命克劳德。
- 底部价值词：更早发现 / 更准判断 / 更快行动。
- 文案要求：每页不超过一个核心判断，正文尽量 1-3 行。

## 文件

- `card-briefs.md`：第一季所有主题的图文卡片结构。
- `01-panorama-xhs.md`：第 01 篇小红书图文细稿和发布文案包。
