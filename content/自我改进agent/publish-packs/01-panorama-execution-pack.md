```text
如果它没有测试结果、错误日志和修改记录，它根本不知道哪次改动有效。
让 Agent 写内容也一样。
如果没有来源检查、风格规则和禁用句式，它下次还会犯同样的错。

25-40 秒：
先做三件事：
定义验收标准。
记录失败原因。
把重复错误写进 Skill 或模板。

40-48 秒：
Agent 想长记性，第一步不是自由更多，是反馈更清楚。
```

### 镜头建议

- 前 3 秒大字：自我进化？先看反馈
- 中段：代码测试结果 / 文章检查清单快速切换
- 结尾：三项 checklist
