# 加更 EvoSkill 实测：失败轨迹如何变成 Skill

状态：brief 完成，是否执行取决于前 5 篇反馈和工具可用性
目标平台：微信公众号或知乎主发，小红书图文/视频和抖音拆条

## 文章功能

这篇是工具实测，不放在第一季主线里。它的任务是回答：自动从失败轨迹提炼 Skill，到底能不能进入个人工作流。

## 核心论点

工具值得测，但不能替代任务定义、验证标准和人工审核。

## 正文骨架

1. 开头：如果失败真的能变成 Skill，个人 Agent 的门槛会下降一大截。
2. EvoSkill 解决什么问题。
3. 安装和运行记录。
4. 输入样本：选择一个低风险任务。
5. 输出检查：
   - 提炼出的 Skill 是否准确。
   - 是否过拟合本次失败。
   - 是否能迁移到相近任务。
6. 与手写 Skill 对比。
7. 是否值得接入个人系统。
