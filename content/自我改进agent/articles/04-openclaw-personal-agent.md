# 04 用 OpenClaw 打造一个会长记性的个人 Agent

状态：brief 完成，待采证后起稿
目标平台：微信公众号主发，小红书图文/视频和抖音拆条

## 文章功能

第四篇是第一季的核心实战。它要把前面三篇的概念落到一个个人可运行的最小系统。

## 核心论点

个人 Agent 的自改进可以先从低风险外环开始：每天读反馈日志，生成 Skill 更新建议，由人审核后合并。

## 正文骨架

1. 开头：真正烦人的不是 Agent 犯错，是同一个错下周还犯。
2. 最小系统边界：
   - 不自动发布。
   - 不自动改高风险配置。
   - 不自动合并 Skill 更新。
3. 架构：
   - 日常 Agent 执行任务。
   - 反馈日志记录结果。
   - OpenClaw 定时触发复盘。
   - 外环 Agent 生成 Skill diff。
   - 人审后合并。
4. 文件结构建议：
   - `feedback-log.md`
   - `skill-update-review.md`
   - `SKILL.md`
   - `CHANGELOG.md`
5. 一个任务示例：公众号诊文或代码巡检。
6. 版本控制和回滚。
7. 第一周怎么跑。

## 不写

- 不承诺自动提升指标。
- 不虚构 OpenClaw 效果数据。
- 不把人工审核省掉。

## 可沉淀资产

- 个人 Agent 自改进目录结构。
- 每日外环复盘 prompt。
