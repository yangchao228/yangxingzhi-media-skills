# 02 从 Loop 到进化：自改进智能体多了一层什么

状态：brief 完成，待采证后起稿
目标平台：微信公众号主发，小红书图文/视频和抖音拆条

## 文章功能

第二篇负责建立专业框架。读者已经知道自改进有条件，这篇要讲清：自改进比 Loop 多出来的是外环。

## 核心论点

普通 Loop 让 Agent 按反馈继续执行。自改进 Loop 让 Agent 把执行经验写回可维护资产，改变下一次执行方式。

## 正文骨架

1. 开头：一个会持续跑的 Agent，未必会成长。
2. 复用前文：Loop 的关键是目标、反馈、停止、边界。
3. 新增一层：外环复盘。
4. 双循环架构：
   - 内环：执行任务、调用工具、验证结果、记录日志。
   - 外环：读取日志、识别重复失败、生成 Skill 更新建议、等待人审。
5. Skill 为什么适合自改进：
   - 文件化。
   - 版本化。
   - 可 diff。
   - 可回滚。
6. 一个具体例子：Issue 分类、内容诊文或 CI 修复。
7. 边界：不是每次失败都改规则，只有重复模式才值得沉淀。
