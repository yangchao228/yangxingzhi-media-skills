# 03 别先谈自动进化，先给 Agent 建一个错题本

状态：brief 完成，待采证后起稿
目标平台：微信公众号主发，小红书图文/视频和抖音拆条

## 文章功能

第三篇从理论落到可立即执行的模板。它要让读者今天就能开始记录 Agent 失败，而不是继续等更强工具。

## 核心论点

Agent 不会自然从失败中学习。失败必须被记录、分类、验证，并在下一次任务前被重新加载。

## 正文骨架

1. 开头：同样的错误教三次，说明你缺的不是提示词，是反馈系统。
2. 为什么聊天记录不能自动等于经验。
3. 一个 Agent 错题本最少要记录什么：
   - 任务目标。
   - 预期结果。
   - 实际结果。
   - 验证证据。
   - 失败类型。
   - 下一次规则。
4. pass/fail 好过 7 分制。
5. 三类反馈：
   - 人工纠偏。
   - 自动检查。
   - 混合审核。
6. 如何在下一轮使用错题本。
7. 什么时候不该写入长期规则。

## 不写

- 不把复盘写成情绪总结。
- 不鼓励把所有聊天记录都塞进记忆。
