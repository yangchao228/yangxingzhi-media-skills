# Agent 进化论：自我改进 Agent

本目录用于维护「AI Agent 自我改进」专题。它承接 Loop Engineering 系列，重点放在 Agent 的反馈、复盘、Skill 更新和人工审核，让这些过程沉淀成可复用的内容资产。

## 当前资产

- `series-plan.md`：执行版专题规划，包含长文、图文、视频矩阵和发布节奏。
- `source-pack.md`：采证包，记录可用来源、待复核事实、反方观点和每篇文章的证据需求。
- `articles/`：公众号长文 brief 和后续正文草稿。
- `publish-packs/`：单篇发布执行包，整合公众号正文、16:9 插图提示词、3:4 贴图提示词、小红书发布版和短视频脚本。
- `image-prompts/`：图片提示词包，所有公众号贴图、小红书图文、视频画面默认在这里交付提示词。
- `wechat-images/`：公众号贴图 / 插图 brief；贴图固定 3:4，插图默认 16:9 且按需生成。
- `xhs-cards/`：小红书图文卡片结构和出图交接。
- `video-scripts/`：小红书视频和抖音短视频脚本。
- `templates/feedback-log.md`：Agent 失败记录和反馈日志模板。
- `templates/skill-update-review.md`：Skill 更新审核模板。
- `Agent 进化论系列 - 自改进智能体选题与大纲.md`：旧版素材池，保留原始 A/B/C 角度和来源校验记录。

## 默认生产流程

1. 先更新 `source-pack.md`，核验当期高波动事实。
2. 在 `articles/` 中完成公众号长文 brief 和正文。
3. 从长文骨架中同步确认公众号正文插图位，插图默认 16:9，优先解释概念、机制和流程。
4. 同步规划 3:4 公众号贴图，服务收藏、转发、评论领取和跨平台复用。
5. 在 `image-prompts/` 中生成可复制到 ChatGPT 的图片提示词，不默认出图。
6. 从长文拆出 `xhs-cards/` 的 8 页图文结构。
7. 从同一主题拆出两条短视频脚本：小红书偏信任，抖音偏增长。
8. 汇总到 `publish-packs/`，形成发布当天可直接使用的执行包。
9. 发布后把评论、收藏、私信问题回写到下一篇 brief。

## 内容边界

- 每篇必须有一个可验证任务、一个反向边界和一个可拿走的模板。
- 视频每条只讲一个判断，不压缩公众号完整大纲。
- 图片类资产默认只产出提示词，用户手动到 ChatGPT 生成高质量图片。
- 所有平台都要回到 Human3.0：人保留判断权，Agent 承担执行和复盘，经验沉淀为数字生产资料。
