# 图片提示词包

本目录是本专题所有图片类产物的默认交付位置。

## 默认规则

- 默认只生成高质量图片提示词。
- 不主动生成图片，不主动批量出图。
- 公众号贴图、公众号插图、小红书图文、视频画面和视频封面都按这个规则处理。
- 用户会手动把提示词复制到 ChatGPT 中生成优质图片。
- 只有用户明确要求“出图”“生成图片”“导出 PNG/JPG”时，才进入图片生成或渲染流程。

## 提示词要求

每条提示词尽量包含：

- 平台：公众号 / 小红书 / 抖音 / 小红书视频。
- 比例：公众号贴图 3:4；公众号插图 16:9；小红书图文 3:4；视频封面 9:16。
- 风格：极简轻科技风、专业克制、清爽可读。
- 文字内容：明确列出图上要出现的中文文字。
- 画面结构：信息层级、布局、图形关系。
- 品牌元素：AI生命克劳德。
- 负向约束：不要二维码、不要机器人拟人、不要夸张科幻、不要文字重叠。
