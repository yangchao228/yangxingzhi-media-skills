## 配套发布文案

昨天那篇 UI 复刻，不是主菜，只是证据。

真正想分享的是背后的开源项目：`loop-builder`。它面向你自己的反复任务，帮助你把任务整理成可控、可验证、可停止、可复用的 Agent Loop。

你只要用一句自然语言描述任务，它会先检查目标、输入、证据和边界，再判断当前更适合 Prompt、Checklist、Human-in-the-Loop、Loop 脚手架、Agent 包，还是专用 Skill。证据不够就先停下补问，工作逻辑确认后再生成正式产物。

仓库当前是 Codex Skill 形态；这套方法可以迁移到其他 Agent 工作流。只要你的工作里有 Agent、有反馈、有人工确认边界，就可以参考它搭自己的 Loop。

第 5 张图放了我真实跑通过的 UI 复刻案例，第 6 张图放了 GitHub 二维码和最小使用句。找一个反复卡住你的任务，先跑一次。

卡片里有开源仓库、提效场景、产物选择和真实证据，保存备用。
