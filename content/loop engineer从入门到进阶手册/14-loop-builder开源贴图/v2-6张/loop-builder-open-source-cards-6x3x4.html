HOW IT WORKS

一句话进去，
先过 5 个判断点

缺证据先补问，逻辑确认后再生成正式产物。

01
真实任务
先说清目标、输入、允许动作和禁止边界
02
上下文与证据
材料是否足以判断复杂度、轮次与风险
03
产物决策
该用 Prompt、Checklist，还是进入 Loop
04
受控策略
设计反馈信号、停止规则与人工确认点
05
可复用资产
人确认工作逻辑后，再生成正式文件
复杂性由工具接住，判断权继续留在人手里。

SMALLEST USEFUL ARTIFACT

先选最轻方案，
再逐级升级

任务形态不同，最合适的交付物也不同。

一次性任务
Prompt
完成一次，且没有稳定的多轮反馈闭环
人工验收
Checklist
标准可以列清，最后主要由人核对
风险动作
Human-in-the-Loop
已有反馈，但关键动作必须先经人确认
多轮修正
Loop 脚手架
反馈明确，可以据此持续检查和修正
同一业务复跑
Agent 包
需要状态、日志和业务专用规则
跨项目复用
专用 Skill
工作流、输入契约与验收方式已经稳定
优先生成当下够用的最轻产物。
