## 配套发布文案

昨天，我把“安心记”首页的 UI 复刻过程写了出来：目标图、当前截图、差异清单，每轮只修 Top 3，再截图验证。

这组图片继续往前一步，拆开背后的开源项目 `loop-builder`。

你只要用一句自然语言描述任务，它会先检查目标、输入、验收信号和操作边界，再判断当前更适合 Prompt、Checklist、Human-in-the-Loop、完整 Loop、专用 Agent，还是可安装 Skill。关键证据不足时先停下补问；工作逻辑确认后，才生成正式产物。

仓库已经包含中英文文档、模板、验证记录，以及 UI 视觉复刻代表案例。第 6 张图放了 GitHub 二维码和最小使用句。先收藏，找一个反复卡住你的真实任务跑一次。

卡片里有工作机制、产物决策和人机边界，保存备用。
