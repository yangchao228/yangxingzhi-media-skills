03 / WHY
WHY LOOP BUILDER

为什么要做 Loop Builder

01
上下文缺失仍继续
缺目标图、失败日志或验收标准，Agent 只能猜。
02
每轮没有外部反馈
没有测试、截图或数据，结果只剩自我确认。
03
没有停止与确认规则
改动扩散、成本上涨，风险动作越过人。
先把执行方式设计清楚，再让 Agent 动手。

04 / WORKFLOW
HOW IT WORKS

一句话进去，它先做 5 个判断

01
Context Gate
关键输入够不够
02
Loop Fit
Prompt、Checklist 还是 Loop
03
Strategy
选择合适的 Loop 模式
04
Logic Confirmation
人先确认执行逻辑
05
Artifact
生成 Prompt、Agent 或 Skill

缺少关键输入时停下来；逻辑确认后再生成正式产物。

06 / RESPONSIBILITY
RESPONSIBILITY

一套 Loop，四方各司其职

Loop Builder
设计工作流：整理输入、反馈、停止与权限。
Agent
执行任务：可以是 Codex、Claude Code 或 Cursor。
Evaluator
提供证据：使用测试、截图、数据和规则验收。
Human
保留判断：确认执行逻辑、高风险动作和最终结果。
公开发布、merge、生产配置、权限与删除始终由人确认。
