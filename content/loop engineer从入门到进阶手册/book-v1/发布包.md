# 《Loop Engineering 从入门到进阶手册》发布包

## 1. 微信读书简介

《Loop Engineering 从入门到进阶手册》是一本面向 AI Agent 实践者的入门手册。

它讨论的重点，是怎么把目标、状态、工具、反馈、停止规则和人的判断边界组织成一个可控循环系统。

书中从 Prompt、Context、Harness、Loop 的演进讲起，拆解一个可控 Loop 的六块积木、五种常见模式，以及 Planner / Generator / Evaluator 三角色闭环。最后用 Codex CLI 搭建一个最小可跑的 CI 自动修复 Loop，并补充模板包、决策表、断路器清单和成本控制清单。

适合读者：

- 正在使用 Codex、Claude Code、Cursor 等 AI 编程工具的开发者。
- 想把 AI Agent 用到真实项目流里的实践者。
- 关注个人系统、数字生产资料和 Human3.0 的长期主义读者。

读完你会拿到：

- 一套判断任务是否适合做 Loop 的方法。
- 一张 Loop 模式决策表。
- 一套 Planner / Maker / Checker / Evaluator 模板。
- 一个 Codex CI 自动修复 Loop 的完整实战案例。
- 一组成本、权限、测试和人工确认边界清单。
