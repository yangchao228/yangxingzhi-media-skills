跨轮次持续推进

人的工作重心，从写提示词，上移到设计反馈、状态和边界。
一个好 Loop，必须满足四条标准
可验证、可停止、可纠错、可交接
✓

可验证

有外部反馈，不靠自我确认

!

可停止

失败、超时、高风险时停下

↺

可纠错

记录失败原因，支持下一轮修正

↗

可交接

别人或下一轮 Agent 能接手

Loop
缺少这四项，自动化越快，风险扩散越快。
三角色闭环：规划、生成、验收分离
不要让同一个 Agent 既实现，又宣布自己通过
Planner

定目标和边界

拆目标、写约束、定义验收标准

Generator / Maker

最小实现

按计划生成、修改、提交可检查结果

Evaluator / Checker

独立验收

验证结果、指出风险、不替生成者背书

角色分离，是减少自我确认和范围失控的基础。
人机确认边界
Agent 准备证据，人保留最终判断权
Agent

可以自动准备

  • 收集上下文和候选方案
  • 运行检查并整理证据
  • 给出风险、差异和建议
  • 生成可交接的记录
|
Human

必须人工确认

  • 生产发布和外部提交
  • 权限、资金和敏感数据
  • 高风险改动和不可逆操作
  • 价值判断和最终取舍
好的 Loop 会把证据推到人面前，而不是替人做最终判断。
