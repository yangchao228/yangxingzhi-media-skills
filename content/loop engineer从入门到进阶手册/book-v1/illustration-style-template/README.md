# Loop Engineering 书内插图统一视觉模板 v1

## 判断

这套插图应统一为“手册结构图”，不是公众号爆款海报，也不是科技大屏。

目标是让读者快速理解关键结构：层级、标准、角色、边界、流程和决策。视觉要有质感，但不能抢正文。

当前有两套候选方向：

- 深色版：更有传播感，适合公众号横版配图和封面式视觉。
- 浅色版：更像书内插图，阅读压力更低，更适合电子书连续阅读。

当前正式采用：浅色版。

## 统一规格

- 画布：`1600 x 900`
- 比例：`16:9`
- 安全边距：左右 `96px`，上下 `72px`
- 背景：深黑到深灰，轻微网格或细线即可
- 主标题：顶部，`56-68px`
- 副标题：标题下方，`28-34px`
- 主体区：只放一个核心结构
- 底部结论：一行，`30-36px`

## 色彩

|---|---:|---|
| 背景 | `#101112` | 深黑主底 |
| 背景层 | `#181B1F` | 模块底 |

| 蓝色 | `#4D8DFF` | 层级、验证 |
| 红色 | `#E75D57` | 停止、风险、人保留判断权 |
| 线框 | `rgba(243,235,221,.18)` | 边框和辅助线 |

## 字体

- 中文：`PingFang SC`, `Noto Sans CJK SC`, `Microsoft YaHei`, sans-serif
- 英文：`Inter`, `SF Pro Display`, sans-serif
- 不使用负字距
- 每张图最多两级文字：标题 / 解释
- 单个模块内中文不超过两行

## 图形语言

- 模块用低圆角矩形，统一边框和微弱发光
- 图标统一为线性符号，不用拟物按钮、警报器、3D 图标
- 箭头统一用细线 + 端点，不用粗光束
- 高光只用于当前图的关键节点
- 结构优先，不用复杂装饰、粒子、光斑、真人、机器人

## 适配 9 张图

| 图 | 结构类型 | 统一做法 |
|---|---|---|
| 01 四层演进 | 横向递进 | 四个同尺寸模块，从 Prompt 到 Loop，Loop 用暖金强调 |
| 02 好 Loop 四要素 | 中心 + 四象限 | 中心 Loop，四周是可验证、可停止、可纠错、可交接 |
| 03 六块积木 | 2x3 矩阵 | 六个一致模块，每块一个关键词和一句定义 |
| 04 Skill vs Memory | 左右对照 | 左 Skill，右 Memory，中间标出差异 |

| 09 人机确认边界 | 左右边界 | Agent 准备证据，人保留最终判断权 |

## 禁用项

- 不使用“赛博大屏”式强霓虹背景
- 不使用拟物红色按钮、金属警报器等强风格元素
- 不使用小字说明堆满画面
- 不让每张图变成独立海报风格
- 不把正文表格完整搬进图里

## 后续生成顺序

1. 使用 `figures-light-export.html` 作为 9 张正式图的结构源。
2. 每张图通过 URL 参数 `?figure=01` 到 `?figure=09` 单独导出。
3. 全部导出为 `1600 x 900` PNG，替换 `book-v1/images/` 中同名文件。

## 当前建议

电子书正式版使用浅色版。它和正文阅读环境更接近，连续出现 9 张图时不容易显得吵。

如果后续还要把这些图拆出来做公众号首图或传播卡片，可以保留深色版作为传播版模板。
