## 前言：为什么我要写这本手册

### 章节目标

解释这本书的来由：Prompt 技巧越来越不够用，真正值得沉淀的是可复用的循环系统。

### 读者收获

- 知道这本书解决什么问题。
- 明白它不是工具说明书，也不追求替人做所有决定。
- 建立一个底层判断：Loop Engineering 是把人的判断、工具调用、反馈和停止规则组织成系统。

### 来源素材

- 第 1 篇。
- 第 5 篇本地实测复盘。

### 新增内容

- 这本书适合谁。
- 不适合谁。
- 如何阅读和实践。

## 第 2 章：Loop 到底是什么

### 章节目标

### 核心问题

- Loop 和 Prompt 有什么区别？
- Loop 和 Workflow 有什么区别？
- Loop 和 Cron Job 有什么区别？
- 一个最小 Loop 需要哪些要素？

### 读者收获

- Loop 最小定义。
- Loop / Prompt / Workflow / Agent / Cron Job 对照表。
- 可验证、可停止、可纠错三条标准。
