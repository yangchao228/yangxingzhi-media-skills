# 微信读书投稿发送清单

## 1. 当前投稿包状态

已完成：

- 投稿完整稿 Markdown
- 投稿完整稿 DOCX
- 投稿完整稿 PDF 预览版
- 作品信息 Markdown
- 作品信息 DOCX
- 投稿邮件正文
- 微信读书投稿包说明

仍需人工确认：

- 投稿邮箱或投稿入口
- 作者联系方式
- 公众号 / 内容账号名称
- 正式封面图

## 2. 建议附件

邮件附件建议放这些：

| 附件 | 文件 |
|---|---|
| 完整书稿 | `Loop Engineering 从入门到进阶手册-投稿完整稿-AI生命克劳德.docx` |
| PDF 预览 | `Loop Engineering 从入门到进阶手册-投稿完整稿-AI生命克劳德.pdf` |
| 作品信息 | `Loop Engineering 从入门到进阶手册-作品信息-AI生命克劳德.docx` |
| 封面图 | `Loop Engineering 从入门到进阶手册-封面-AI生命克劳德.png` |
| 书内配图目录 | `images/` |

封面未完成时，可以先不附封面，并在邮件正文中写“封面图可按平台要求后续补充”。

当前 `images/` 目录已有 9 张 1600x900 横版配图。若导出脚本尚未支持图片嵌入，投稿时需要单独附上 `images/` 目录或压缩包。

## 3. 邮件主题

```text
短篇作品+Loop Engineering 从入门到进阶手册+约2.5万字
```

## 4. 邮件正文使用文件

使用：

`Loop Engineering 从入门到进阶手册-投稿邮件-AI生命克劳德.md`

发送前替换：

- `联系方式：微信 / 手机 / 邮箱`
- `公众号：填写公众号名称`
- 如果已附封面，将“封面图，如已完成”改为“封面图”

## 5. 投稿入口确认

当前没有在公开网页中核到稳定的微信读书官方投稿邮箱说明。

建议确认顺序：

1. 微信读书 App 内：我的 -> 帮助与反馈，搜索“投稿 / 版权 / 作者投稿”。
2. 若 App 内确认 `wxzg@tencent.com`，再按该邮箱发送。
3. 若 App 内给出新的投稿入口，以 App 内入口为准。
4. 发送后记录投递时间、邮箱、主题和附件版本。

## 6. 发送前最终检查

- [ ] 邮件主题使用约 2.5 万字版本。
- [ ] 邮件正文已替换真实联系方式。
- [ ] 邮件正文已替换公众号 / 内容账号名称。
- [ ] 版权说明保留“原创文章整理扩写，部分基础内容曾发布”。
- [ ] 附件包含 DOCX。
- [ ] PDF 只作为预览附件。
- [ ] `images/` 目录已包含 9 张 1600x900 横版最终配图。
- [ ] 如无正式封面，正文说明后续可补。
- [ ] 不把投稿邮箱写成“已官方核实”，除非已在 App 内确认。
