# 小红书默认视觉与分发交接

## 默认选择

文昌小红书图文默认调用已安装的 `baoyu-xhs-images`：`sketch-notes` 风格、`macaron` 配色、中文、3:4 竖图。该默认已由用户选定；用户本次指定的其他风格优先。归藏、HTML 卡片及其他旧工具保留为可选方案，不自动替换默认。

宝玉 Skill 为单独安装的依赖，本仓库不内嵌第三方源码。先定位并读取其 `SKILL.md`；缺失时说明需补装，可先整理文案与页纲，不能宣称已生成宝玉成图。项目偏好保存在仓库根 `.baoyu-skills/baoyu-xhs-images/EXTEND.md`；在其他工作目录调用时显式传递上述风格和配色，不假定该文件自动生效。

## 视觉约定

- 暖奶油纸底 `#F5F0E8`，深灰文字 `#2C3E50`；粉蓝、淡紫、薄荷绿、桃色分区，珊瑚红 `#E8655A` 少量强调关键词。
- 手绘中文大标题、轻微不规则线条、简洁概念插图和清晰信息层级。每页一个重点，给正文和图解留空间，避免小字堆积及装饰抢占信息。
- 页数由内容与已确认方案决定，不固定六页，也不强行补成九页。封面、流程、对比、清单等逐页选布局，保持字体、人物、色彩和页码一致。
- 封面主标题 5–20 个 Unicode 字符；发布标题不超过 20 字，两者表达同一核心判断但不完全重复。独立描述 150–300 字，不照抄长文。已有草稿只换图时保留标题和正文，不借机改写。

## 生成与本地验收

1. 读取唯一正式稿、已确认文案/页纲及可复用图片。记录源稿哈希；将大纲、逐页文案、完整提示词写入衍生目录，勿混入正式稿。沿用已确认选择；按生成 Skill 的确认规则补齐尚缺决策，不把偏好文件视为外部上传授权。
2. Codex 中按 `imagegen` Skill 使用原生生图工具。先生成封面作为整套参考图，后续每页传入该封面。补齐卡片时复用已确认封面与旧页，只生成缺页；不重绘已确认原图。
3. 每页提示词先落盘再生图。出现错字、漏项或风格漂移时，在新版本修正该页提示词并重生成，保留旧版。不要用 HTML/CSS 绘图代替宝玉成图，也不要靠程序叠字掩盖生成错误；HTML 只承载本地预览。
4. 逐张看图，核对中文、数字、流程方向、阅读顺序、手机尺寸可读性和整套风格。清单记录有序文件、实际尺寸、哈希及所用参考图；未经目视检查不得宣称视觉通过。
5. 先交付可打开、可翻页的本地预览。用户只要求本地预览时，到此停止。生成、上传、草稿保存和发布分别记录；默认不发布。

## 原图尺寸兼容

分发工具接收静态 PNG/JPEG/WebP，要求宽度至少 1080 像素，且 `width * 4 === height * 3`。例如 1080×1440、1086×1448、1200×1600 均通过；1080×1080、720×960 不通过。这是项目分发约定，不代表平台唯一支持尺寸。

合规原图按字节保留，不强制缩放到 1080×1440、不裁切、不重绘。预览使用每张图真实宽高；上传计划和重开验收也使用实际尺寸。GIF、超过现有文件大小限制或比例/分辨率不合规的图片先作为阻塞项处理，不放宽校验或偷偷转换。

## 从已确认图片更新草稿

1. 只更新 `distribution/derived/xiaohongshu-cards.json` 的有序图片引用，以及用户要求修改的小红书平台配置。路径相对 distribution；不改正式稿，不顺带同步其他平台。旧图、旧构建和旧回读证据保留。
2. 按 [三平台操作手册](draft-sync.md) 重新 build/check，然后运行 `xhs-cli prepare`。复用 R2 upload-only 映射中哈希一致的素材；仅在已授权的同步范围内上传缺图。上传使用 plan 的有序本地副本，不把 R2 URL 粘入正文替代图片。
3. 按 [Chrome 操作流程](chrome-drafts.md) 更新既有记录：核验账号与同名稿 → 比较已有标题/正文 → 替换图片 → 等待全部加载 → 暂存离开 → 新标签从列表重开 → 逐图与正文验收。只点击保存草稿，绝不发布或排期。
4. 若已存在用户编辑、同名多稿、保存结果不明或本地文案与页面冲突，先保留并核对，不能盲目覆盖或另建副本。只有当前版本独立回读通过，才记录 `draft_verified`。

可复用的 Skill、代码和合成测试可提交 Git；正式稿、成图、在线截图、浏览器证据、凭证和带签名的地址留在本地。
